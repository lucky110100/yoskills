# 安全性 — 维度分析卡（否决项）

> 维度归属：E 外部质量组。**否决项：本维度=0 即整体计 1 否决。** 评估鉴权、加密、注入、密钥管理、依赖 CVE、日志脱敏。

## 评估信号（发现即记，高危即拉否决）

- 密钥/凭证硬编码或入库（password=、token=、API_KEY= 字面量）
- 无鉴权或越权（接口无权限校验、IDOR 可越权访问他人资源）
- SQL 注入/XSS/CSRF 风险点（拼接 SQL、未转义输出、无 CSRF token）
- 依赖含已知 CVE
- 敏感数据明文传输/存储（HTTP 传密码、明文存）
- 日志含敏感信息（打印完整密码/token）
- 无输入校验（直接信任外部输入）

## 评估工具与命令

| 工具 | 命令/用法 | 看什么 |
|------|----------|--------|
| Grep | 查密钥模式 `password\s*=|token\s*=|key\s*=` | 硬编码密钥 |
| semgrep | 安全规则集 | 注入/XSS/越权模式 |
| RunCommand | `npm audit`/`snyk test`/`trivy fs`/`mvn dependency-check` | 依赖 CVE |
| Grep | 日志打印处 + 敏感字段名 | 日志泄露 |
| ast-grep | 拼接 SQL 模式 | 注入风险 |
| git log -p | 查历史是否曾泄露密钥 | 历史泄露 |

## 评分锚点（5 档判定）

| 分 | 锚点信号 |
|----|---------|
| 4 | 无硬编码密钥(用密钥管理服务) + 鉴权完整 + 输入校验 + 依赖无 CVE + 加密传输存储 + 日志脱敏 + 有安全扫描 CI 门禁 |
| 3 | 鉴权完整 + 无硬编码 + 依赖偶有低危 CVE + 基本输入校验 |
| 2 | 鉴权基本完整 + 部分输入校验缺失 + 偶有日志敏感信息 |
| 1 | 鉴权不全或有越权/注入风险点 + 无输入校验 |
| 0 | 无鉴权 或 硬编码密钥 或 已知高危 CVE 未修（触发否决） |

## 规范基线（新项目应做/不做）

- ✅ 应：密钥用密钥管理服务/环境变量 + 鉴权全覆盖 + 输入校验 + 依赖漏洞扫描 CI 门禁 + 加密传输存储 + 日志脱敏中间件
- ❌ 不做：硬编码密钥 + 明文存密码 + 信任外部输入 + 日志打印完整凭证 + 跳过鉴权的"临时"接口

## 对标要点（业界标杆看哪些）

- 看标杆项目的安全配置（鉴权中间件、加密策略、密钥管理）
- 看其安全扫描 CI 配置（snyk/trivy/dependency-check 门禁）
- 看其输入校验与 OWASP Top 10 防护实践

## 反模式

```
❌ 密钥写代码里"临时调试"后忘记删（高危）
❌ 鉴权只在部分接口加（越权漏洞）
❌ 依赖从不扫 CVE（供应链风险）
❌ 日志打印完整请求体（含密码）
❌ "内网不用加密"（边界一旦突破即裸奔）
```

## Checklist

- [ ] 是否查了硬编码密钥
- [ ] 鉴权是否覆盖所有需保护接口
- [ ] 是否扫了依赖 CVE
- [ ] 是否查了注入风险点
- [ ] 日志是否脱敏
- [ ] 输入校验是否到位
