# 业界标杆库索引

> 本目录沉淀各技术栈的业界优秀项目，供 `project-analysis` 对标模式使用。每个标杆项目记录「看哪些目录/文件/配置」与「浅对标源/深对标提示」，避免每次重新搜索。
>
> **沉淀原则：** 每次评估后新发现的优秀标杆应回写到此库；不在库的技术栈先用 WebSearch 即时找，评估合格后沉淀。

## 标杆项目条目格式（每个 `<tech>.md` 内遵循）

```markdown
## <项目名>
- 仓库: https://github.com/...
- 类型: 框架 | 应用 | 库
- 亮点维度: 安全性 / 可观测性 / 架构约束 / ...
- 对标要点: 看 <目录/文件/配置>
- 浅对标源: README / architecture.md / 官方文档链接
- 深对标提示: clone 后跑 <feature-analysis / 读 dims/<维度>.md>
```

## 补充流程

1. 评估/对标模式中 WebSearch 发现优秀项目
2. 读其 README/架构文档评估「是否够格作标杆」(看其在该维度的实践是否值得学)
3. 合格则按上述格式写入对应 `<tech>.md`(不存在则新建)
4. 记录亮点维度与对标要点,供后续直接复用
