## 完整的租户隔离热加载调用链路

### 一、初始化阶段（DeepAgent 构造 → SkillUseRail.init）

```
DeepAgent(card, config, workspace)
  ├─ config.isEnableTenantIsolation() == true
  │   └─ workspaceResolver = new TenantWorkspaceResolver(tenantDataRoot)
  │
  └─ SkillUseRail.init(deepAgent)
      ├─ skillManager = new SkillManager(agentId)             ← 公共 SkillManager
      ├─ deepAgent.isTenantIsolationEnabled() && getWorkspaceResolver() != null
      │   ├─ railWorkspaceResolver = deepAgent.getWorkspaceResolver()   ← 共用同一 resolver
      │   ├─ tenantSkillManager = new SkillManager(agentId + ".tenant") ← 租户 SkillManager
      │   ├─ overlayDir = resolver.resolveTenantRoot(...).resolve(".overlay")
      │   ├─ overlaySkillManager = new OverlaySkillManager(tenantSM, publicSM, overlayDir, resolver)
      │   ├─ listSkillTool = new ListSkillTool(skillsRoot, resolver, overlaySM)  ← ★传入 Overlay
      │   └─ skillTool = new SkillTool(skillsRoot, resolver, overlaySM)          ← ★传入 Overlay
      │
      └─ reloadSkills() → prepareSkills()
          ├─ collectSkillRoots() → [public skillsRoot]  ← init 时无 TenantContext
          ├─ skillManager.refreshIncrementally([skillsRoot])           ← 刷新公共技能
          └─ tenantSkillManager: 无 TenantContext，跳过租户刷新      ← init 时暂不加载租户技能
```

### 二、运行阶段（DeepAgent.invoke → 技能热加载 → 模型调用）

```
agent.invoke(inputs, session)   ← session携带 TenantContext(tenantId)
  │
  ├─ TenantContextHolder.setCurrentTenant(ctx)              ← 绑定线程租户身份
  ├─ bindTenantWorkspace(ctx)                               ← 绑定租户工作空间
  │   ├─ workspaceResolver.initializeTenantSpace(ctx)
  │   │   └─ 创建: {base}/tenants/{tenantId}/skills
  │   │   └─ 创建: {base}/tenants/{tenantId}/.overlay
  │   ├─ CwdContext.setWorkspace/setTenantRoot → 租户路径
  │
  ├─ invokeInternal(inputs, session)
  │   │
  │   ├─ SkillUseRail.beforeModelCall(ctx)                 ← ★每次模型调用前触发
  │   │   ├─ buildCurrentSignature()
  │   │   │   ├─ collectSkillRoots()
  │   │   │   │   ├─ [配置目录 + skillsRoot]               ← 公共根
  │   │   │   │   ├─ + TenantContextHolder.getCurrentTenant()
  │   │   │   │   │   └─ railWorkspaceResolver.resolveSkillRoot(ctx)
  │   │   │   │   │      → {base}/tenants/{tenantId}/skills ← ★动态加入租户根
  │   │   │   │   └─ roots = [公共根, 租户根]
  │   │   │   └─ skillManager.buildSnapshotSignature(roots) ← 签名包含公共+租户根
  │   │   │
  │   │   ├─ signaturesEqual(current, cached)?
  │   │   │   ├─ 不同 → prepareSkills()
  │   │   │   │   ├─ skillManager.refreshIncrementally(roots)  ← 刷新公共 SkillManager
  │   │   │   │   │   └─ 只扫描公共根下的 SKILL.md（租户根的skill不会被注册到公共SM）
  │   │   │   │   │
  │   │   │   │   └─ tenantSkillManager.refreshIncrementally([tenantSkillRoot])  ← ★刷新租户 SM
  │   │   │   │       └─ 扫描 {base}/tenants/{tenantId}/skills/ 下所有 SKILL.md
  │   │   │   │       └─ 仅注册当前租户的私有技能
  │   │   │   │
  │   │   │   └─ 相同 → 跳过刷新
  │   │   │
  │   │   └─ injectSkillPrompt(ctx)                         ← ★注入合并视图的技能 prompt
  │   │       ├─ overlaySkillManager.getAllVisibleSkills()
  │   │       │   ├─ TenantContextHolder.getCurrentTenant() → ctx
  │   │       │   ├─ tenantSkillManager.getAll()              ← 租户私有技能（优先）
  │   │       │   │   └─ ["tenantSkill-a", "sharedSkill(租户版)"]
  │   │       │   ├─ publicSkillManager.getAll()              ← 公共技能（排除被覆盖的）
  │   │       │   │   └─ ["publicSkill-b"]  ← sharedSkill 被租户覆盖，不出现
  │   │       │   └─ 合并结果: [tenantSkill-a, sharedSkill(租户版), publicSkill-b]
  │   │       └─ buildSkillPrompt(language, mode, mergedSkills)
  │   │       └─ addPromptBuilderSection("skills", prompt)
  │   │
  │   ├─ 模型推理 (LLM 调用)
  │   │
  │   ├─ LLM 返回 tool_call: skill_tool(skill_name="sharedSkill")
  │   │   └─ SkillUseRail.readSkill(inputs)
  │   │       ├─ overlaySkillManager.getAllVisibleSkills()     ← ★校验可见性
  │   │       │   ─ "sharedSkill" 在租户版可见 → 通过校验
  │   │       ├─ skillTool.readSkill("sharedSkill", "SKILL.md")
  │   │       │   ├─ overlaySkillManager.resolveSkillFile("sharedSkill", "SKILL.md")
  │   │       │   │   ├─ TenantContextHolder.getCurrentTenant() → ctx
  │   │       │   │   ├─ workspaceResolver.resolveSkillRoot(ctx)
  │   │       │   │   │   → {base}/tenants/{tenantId}/skills
  │   │       │   │   ├─ tenantSkillRoot.resolve("sharedSkill/SKILL.md")
  │   │       │   │   │   → {base}/tenants/{tenantId}/skills/sharedSkill/SKILL.md ← ★租户版
  │   │       │   │   └─ Files.exists(tenantTarget) == true → 返回租户版路径
  │   │       │   └─ readSkillFile(skillDir, tenantTarget)    ← 读取租户版技能内容
  │   │       └─ 返回租户版 SKILL.md 内容
  │   │
  │   ├─ LLM 返回 tool_call: list_skill()
  │   │   └─ SkillUseRail.listSkill(inputs)
  │   │       ├─ filterSkills(query)
  │   │       │   ├─ overlaySkillManager.getAllVisibleSkills() ← ★合并视图
  │   │       │   └─ configuredSkills(mergedSkills)            ← 按 enabled/disabled 过滤
  │   │       └─ 返回技能名称列表
  │   │
  │   ├─ ListSkillTool.listSkills() (也可直接调用)
  │   │   ├─ overlaySkillManager != null ?
  │   │   │   ├─ overlaySkillManager.getAllVisibleSkillNames() ← ★合并名称列表
  │   │   │   └─ 返回排序后的技能名列表
  │   │   └─ 否: collectDefaultSkills() (公共+租户手动合并)
  │   │
  │   └─ 后续推理循环...
  │
  └─ finally:
      ├─ TenantContextHolder.clearCurrentTenant()   ← 清除线程租户身份
      └─ unbindTenantWorkspace() → CwdContext.reset() ← 清除工作空间上下文
```

### 三、热加载变更检测链路

```
文件变更（新增/修改/删除 SKILL.md）
  │
  ├─ 下次 beforeModelCall() 时:
  │   ├─ buildCurrentSignature()
  │   │   └─ collectSkillRoots() → [公共根, 租户根(如果当前有租户上下文)]
  │   │   └─ skillManager.buildSnapshotSignature(roots)
  │   │       └─ 对每个 root 下每个子目录的 SKILL.md 计算 mtime
  │   │       └─ 返回 [(目录路径, mtime), ...]
  │   │
  │   ├─ signaturesEqual(current, cached)?
  │   │   └─ mtime 变化 → 不相等
  │   │
  │   └─ prepareSkills()
  │   │   ├─ skillManager.refreshIncrementally(roots)
  │   │   │   └─ 公共 SkillManager: 只刷新公共根下有变化的技能
  │   │   │
  │   │   └─ tenantSkillManager.refreshIncrementally([tenantSkillRoot])
  │   │       └─ 租户 SkillManager: 只刷新租户根下有变化的技能
  │   │       └─ mtime 比较 → 仅重新解析变化的 SKILL.md
  │   │       └─ 过期清理 → 移除磁盘上已不存在的技能
  │   │
  │   └─ overlaySkillManager.getAllVisibleSkills()
  │   │   └─ 读取 tenantSkillManager.getAll() + publicSkillManager.getAll()
  │   │   └─ 合并视图自动反映最新状态
  │   │
  │   └─ injectSkillPrompt(ctx) → 更新 prompt
```

### 四、OverlaySkillManager 合并规则详解

| 场景 | 合并结果 |
|---|---|
| 租户有 `skillX`，公共也有 `skillX` | **租户版优先**，公共版被遮蔽（同名覆盖） |
| 租户有 `skillX`，公共没有 | **租户版独立可见** |
| 公共有 `skillY`，租户没有 | **公共版可见**（回退） |
| 公共有 `skillY`，租户有 `.override/skillY.override` 标记 | **公共版被遮蔽**，即使租户没有同名技能 |
| 无 TenantContext | **只返回公共技能列表** |
| TenantContext 无租户ID | **只返回公共技能列表** |
